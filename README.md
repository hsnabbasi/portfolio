# Hassan Fayyaz Abbasi Portfolio

Personal portfolio website for Hassan Fayyaz Abbasi, built with Next.js and Tailwind CSS.

## Overview

This portfolio highlights:

- professional summary
- work experience
- skills
- AI and LLM projects
- software projects
- education
- contact information
- latest CV download

## Run Locally

From the project root:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
